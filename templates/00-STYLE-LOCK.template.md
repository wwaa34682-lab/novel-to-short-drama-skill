# STYLE-LOCK（项目视觉 / 语言 / 后端锁）· 模板

> 复制到项目根目录改名 `STYLE-LOCK.md`，开工前和用户逐项填死。之后每份提示词都从这里抄「全局一致性块」。
> 方括号里是示例，**不是默认值**，按你的项目改。

## 1. 审美与题材
- 题材：[例：末日 / 都市悬疑 / 仙侠 / 校园]
- 画风（只能选一个，写死）：[例：photoreal 仿真人写实实拍质感]
- 禁止的画风表述：[例：二次元、半写实国漫、3D 卡通]
- 时代 / 空间：[例：现代中国城市；禁止古装、古城墙等古代元素]

## 2. 人物
- 面孔 / 族裔：[例：中国 / 东亚面孔；禁止外国人脸]
- 主角身份锁：性别 [ ]、年龄段 [ ]、发型 [ ]、固定服装 [ ]（跨 Clip 不换装，只按状态/战损递进）
- 人物资产规格：白底四视图一张合成（正面全身 + 侧面 + 背面 + 正面半身），无背景
- 配角性别年龄登记表：[角色 | 性别 | 年龄段 | 关键外观]

## 3. 时间与光
- 昼夜：[例：本段全程夜戏；室内 = 夜 + 弱灯，窗外仍黑；禁止白天]
- 光源设定：[例：全城停电，楼窗全黑，只有应急灯、零星火光、能力光]
- 能力 / 特效色彩锁：[例：火系 = 橙红焰尾；冰系 = 冰蓝寒气；禁止其他颜色]

## 4. 场景身份
- 反复出现的地点一律写同一个身份：[例：小型红砖社区医院，门诊楼 + 小住院部]
- 画面里不出现可读文字：招牌、标语、路牌、车标、外文字母（文字后期加）

## 5. 语言
- 提示词正文语言：[中文 / 英文 / 混写]（英文可以让风格更稳定）
- 对白与心声语言：[例：中文]。禁令句：`Dialogue and inner voice must be spoken in <目标语言> only; no foreign-language lines or on-screen captions.`
- 固定结尾：不要生成字幕，不要生成背景音乐；画面上不要出现任何字幕文字。

## 6. 打斗 / 武器（如适用）
- 禁止：[例：冲锋枪阵列、枪口怼镜头的队形、弹壳满天飞的枪战片感]
- 允许：[例：侧面单枪；能力软写成冲击波 / 焰尾 / 符纹]

## 7. 合规 / 版权
- 不拍：烟盒、品牌、Logo、商标特写；裸露写成穿着病号服等安全替代
- 敏感词清单（会被审核拦的词）：[例：血腥、脑浆等]，提示词里换成软化写法

## 8. 后端（示例：LibTV 画布 + Seedance）
- 静帧模型：[ ]，画幅 [16:9 / 9:16]，分辨率 [ ]
- 视频模型：[例：Seedance 2.0 非 Fast]，清晰度 [例：480P]，时长 [约 15 秒]
- 每条视频挂参考图：1 张（最多 2 张）
- 成本策略：复用优先，只单张单条重出，不整批刷

## 9. 全局一致性块（从上面抄成一段，每条提示词开头整段粘贴）
```
【全局一致性】<画风>；<时代空间>；<昼夜>；<面孔>；禁止<…>、九宫格分屏。
<光源设定>。<场景身份>；画面不出现任何可读文字。
<主角服装锁>；全程不换装，只按状态递进。
<特效色彩锁>；<武器拍法>。
对白和心声只用<语言>；禁止外语台词和字幕。
```
