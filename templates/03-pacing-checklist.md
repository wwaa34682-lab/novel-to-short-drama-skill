# 步骤3 · 短视频平台压节奏清单

> 输入：步骤2【正式验收通过】稿 + 验收报告里的 P1。只压表达层，情节锁零改。

## 结构
- [ ] 每场都是「行动 → 阻碍 → 再行动」，开场 3 秒就有事
- [ ] 删掉和本集推进无关的闪回、背景回顾、重复说明
- [ ] 长心声墙压成一句判断 + 短要点 + 一个可视动作确认（握紧、呼气、肩膀绷直等）
- [ ] 先消化了验收报告里的 P1

## 不能过度压缩（踩过的坑）
- [ ] **推进剧情的因果桥一个都没删**（为什么去、为什么不带人、为什么选这条路……）
- [ ] 情绪转折处留了**半拍喘息**：反应镜、空镜、停顿。不是注水，也不是把高潮硬切成串烧
- [ ] 带情绪的关键台词都在（哭喊、拒绝、应允、大喊指令）
- [ ] 台词没被砍成电报句（见 `dialogue-style-guide.md`）
