# 步骤6 · 关键静帧出图 + 目视审查清单

## A. 出哪些图（看结果定，不按纸面一镜一张）
每个 Clip 只出关键节拍：
1. **开场承接**：和上一 Clip 结尾接得上
2. **冲突升级**：本 Clip 最关键的动作或钉点
3. **过渡钉**：一定要拍清的过渡（拿到道具、换场景）
4. **收束**：交给下一 Clip 的状态

同一个镜头里的小推拉不拆成好几张；没用的不出。目标是每 Clip **至少 1 张能当步骤7 参考图的 ✅**。

## B. 怎么审（必须真看，不能凭记忆或提示词打勾）
- 拿全尺寸原图来看（缩略图会漏问题），人脸、手、武器、背景里的文字都裁出来放大看。
- 逐张对照：该 Clip 纸面分镜、资产登记表、`STYLE-LOCK.md`、错误台账。
- 每张给结论：✅ 通过 / ⚠️ 小问题（能当参考，问题写进步骤7 提示词补救）/ ❌ 不通过（单张重出）。
- 先汇总**跨图的全局问题**（同一个地点叫法不同、光线和设定冲突、服装飘、特效颜色不统一），统一改进全局一致性块。
- 重出后再审一轮，还是不行就换方案（比如换一张当参考、改用参考图模式而不是首帧），别无限刷。

## C. 逐张检查项
- [ ] **面孔**：符合风格锁（例：东亚面孔），没有换脸、两个角色长串了
- [ ] **性别 / 年龄**：和角色表一致
- [ ] **昼夜 / 光线**：没有白天；停电设定下没有满城灯火
- [ ] **构图**：没有九宫格、拼图、分屏
- [ ] **画风 / 年代**：没有古装、二次元、半写实
- [ ] **场景**：内外景没拍反（室内戏没跑到室外），地点身份前后一致
- [ ] **服装**：主角固定服装和装备都在
- [ ] **因果 / 动作**：谁攻击谁、特效从谁身上发出、打中了谁，都对
- [ ] **武器**：没有枪阵、没有枪口怼镜头
- [ ] **特效颜色**：符合色彩锁
- [ ] **造型**：怪物、道具和资产一致
- [ ] **可读文字**：画面里没有招牌字、外文字母（有的话就不能当视频参考）
- [ ] **AI 坏点**：多肢、融手、重复的人
- [ ] **重复**：和相邻那张不是同一张图换个说法
- [ ] **尺度 / 合规**：没有越界裸露、血腥特写

## D. 报告结构
1. 统计：✅ / ⚠️ / ❌ 各几张
2. 全部图都没问题的项
3. 全局问题 + 统一改法（英文短语可以直接贴进提示词）
4. 逐张结论（按 Clip 分组：结论、问题、改法）
5. 对步骤7 的影响：每个 Clip 能不能挑出 1 张参考图
6. 重出清单：按优先级排，**单张改，不整批刷**
7. 声明：本报告没动画布、没出图、没生成

审完交用户审，用户放行后才能进步骤7。
