# 步骤8 · 后期剪辑成片（素材包 + 时间线表 + 成片终检）

> 输入：步骤7 全部通过的视频 + 台词定稿 + 系列包装（封面 / 片头 / 片尾模板）。
> 分工：**AI 准备素材**（按顺序排好的片段清单、字幕文件、配音台本、时间线表、封面、可选的粗剪），**真人在剪辑软件里精剪**（例：剪映 / CapCut，其他 NLE 同理）。AI 也可以用 ffmpeg 出粗剪给人参考，但终版以人工确认为准。
> 闸门：成片终检（第 9 节）全过 + 用户看完整片确认，才算【成片通过】可以发布。发布本身是外发动作，要用户明确同意。

---

## 1. 素材清单（状态机，先核素材再剪）

每个 Clip 一行，状态只有四种：

| 状态 | 含义 | 剪辑时怎么处理 |
|---|---|---|
| `ready` | 最新、已审过的终版，本地文件已就位 | 正常上轨 |
| `regen` | 已知要换新片（还在重出或待审） | 用彩条/占位，或旧片打「待换」水印；**不当终稿** |
| `missing` | 没有片（生成失败、被拦） | **跳过**；不要拿别的片段或草稿顶替 |
| `stale` | 旧版 / 草稿 / 来源不明 | **不准上轨**；查清来源后删掉或改标 |

`media-manifest`（JSON 或表格都行）每行写：

| Clip | 标题 | 版本号 / 生成批次 | 本地文件 | 实测时长 | 来源核对（和步骤7 索引表对得上？） | 状态 |
|---|---|---|---|---|---|---|
| X-1① | <概括> | v<n> | `clips/X-1-1_v<n>.mp4` | 15.07s | ✅ | ready |

核素材规则：
- [ ] 文件名带 Clip 号 + 版本号，例如 `X-1-1_v3.mp4`，按文件名排序就是 Clip 顺序
- [ ] 每个文件都对上步骤7 索引表里那一条的**最新**生成结果（看生成时间、首帧、台词内容）
- [ ] 画布里「能播放」不等于本地已下载：先全部落盘，再开剪
- [ ] 时间线上出现**剧本里没有的内容**（多出来的人物、场景、动作）→ 多半是旧草稿或别的 Clip 串进来了，先查来源

## 2. 时间线表（模板）

项目：<剧名> 第<N>集｜画幅 <9:16 1080×1920 / 16:9 1920×1080>｜帧率 <与素材一致>
封面：<第N集封面文件>（集数核对：____）｜片头：<系列片头模板>｜片尾：<系列片尾模板>

### 分轨
| 轨 | 内容 | 默认处理 |
|---|---|---|
| V1 主轨 | 各 Clip 按顺序拼接 | 去头去尾空帧 |
| V0 铺底（竖屏外壳用） | V1 复制、放大、高斯模糊 | 压暗一点，主画面盖在中间 |
| V2 叠字 / 特效 | 生成时故意不让模型写的可读文字（符文、招牌、纸条）、标题、「未完待续」 | 跟着画面钉点出现 |
| A1 原片声 | 视频自带的环境声和动作声 | -18～-24 dB 或静音，保留爆点 |
| A2 配音 | 对白 + 心声 | 对白 0 dB 基准；心声 -3～-6 dB |
| A3 BGM | 分段情绪垫乐 | 对白下面压到 -12～-18 dB（自动闪避）；打斗可以抬高 |
| A4 音效 | 拟音、关键动作的硬响 | 对齐动作帧 |
| T 字幕 | 字幕文件 | 对齐口型/画面后定稿 |

### 时间线总览
| 序 | 内容 | 入点～出点 | 状态 | 文件 | 接点 / 备注 |
|---|---|---|---|---|---|
| 0 | 封面帧 / 片头 | 00:00.0～00:01.0 | — | <cover / opening> | |
| 1 | Clip X-1① | 00:01.0～00:16.0 | ready | `X-1-1_v3.mp4` | 入点：<动作峰值>；出点：<反应定住半拍> |
| … | | | | | |
| n | 片尾 | | — | <系列片尾模板> | 原样复用，不重做 |

### 每个 Clip 的剪法
- **入点**：去掉开头的静帧和起势空镜，从第一个有信息的动作开始
- **出点**：情绪句后留半拍（0.3～0.5 秒）再切，别把上一句的情绪硬切掉
- **接点**：动作接动作，用硬切或 2～4 帧交叉；场景切换可以短暗场
- **关键钉点**：<本 Clip 必须让观众看清的动作/道具/心声>，不能剪掉或剪糊

## 3. 连续看（先粗剪，从头到尾不暂停看一遍）
- [ ] 每个接点：人物位置、服装、战损、道具状态和上一条的【交给下一条】一致
- [ ] 没有重复动作（上一条结尾和下一条开头演了两遍同一件事）→ 剪掉重复的一边
- [ ] 前紧后松 / 中段静音空档：多半是配音或心声没贴，不是镜头不够
- [ ] 陌生观众第一次看能看懂（开场有「谁、在哪、要干嘛」的信息）

## 4. 字幕
- 语言：只用目标语言；和最终台词稿逐字核对（台词定稿版本：____）
- 时机：口型/表情起势后 +2～4 帧出现，切镜前略早结束
- 样式：白字黑描边，居中偏下，一行 ≤14 个汉字（太长拆两行）；心声可以加前缀「（心声）」、小一号或斜体；不要花字、弹跳、飞入
- 安全区：竖屏字幕和关键信息放在画面中间 60%，避开平台上下的 UI
- 如果 AI 先按「每条 15 秒」估算出 SRT，要标 `TODO-ALIGN`，剪辑时按画面重新对齐后去掉

## 5. 配音 / 心声
- 配音台本：每条一行（Clip | 类型 对白/心声 | 角色 | 台词 | 表演提示）
- 文件命名：`vo-<clip>-<dui|xin>-<序>.wav`（建议 48kHz / 24bit）
- 心声：同一音色，轻一点、贴耳一点；前面留 150～300 ms 气口；不和对白叠在一起
- **关键心声（推进剧情、集尾钩子）必须贴上、听得清**，不能变成无声空档
- 视频自带的口型和配音对不上时：优先用配音，模型自带的人声压低或静音

## 6. 音乐与音效
- BGM 按情绪分段（紧张 / 释然 / 悬疑 / 钩子），段落交界交叉淡化 0.3～0.5 秒
- 心声和关键对白下面自动闪避
- 关键动作（锁门、碎裂、斩击）配硬响音效，对齐到帧
- 只用有授权的音乐和音效（平台曲库或可商用素材）

## 7. 包装（系列统一）
- **封面**：用系列封面模板，**集数角标核对两遍**（第几集，是否和发布计划一致）
- **片头 / 片尾**：复用系列已有模板，不要每集重做；本集没有正式的结尾钩子片段时，不要拿草稿凑
- **叠字**：生成时故意空着的可读文字（符文、招牌、关键字条）在这里加，位置、时长跟着钉点
- **冷开场**（可选）：用本集最强的一个画面或一句心声做 1～3 秒钩子，不剧透后文

## 8. 画幅与导出
- 目标平台是竖屏（例：抖音 9:16）而素材是 16:9：
  - A（默认）：9:16 画布，原片居中，上下用同一帧放大模糊铺底（模糊 40～60，略压暗）
  - B（特写段）：裁成全屏，用关键帧跟住人脸或动作焦点，小心别裁掉关键信息
  - 或者从步骤4 起就按 9:16 原生生成（在 STYLE-LOCK 里定）
- 低分辨率素材：用剪辑软件自带的超清/画质增强，别过度锐化
- 编码：H.264；竖屏 1080×1920 码率 ≥8 Mbps；帧率和素材一致，别混帧率
- 音频：AAC 320 kbps；响度约 -14 LUFS（短视频平台常用），加限幅防爆音
- ffmpeg 竖屏外壳示例（AI 出粗剪时用）：
```bash
ffmpeg -i in.mp4 -filter_complex \
"[0:v]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,gblur=sigma=25,eq=brightness=-0.08[bg];\
[0:v]scale=1080:-2[fg];[bg][fg]overlay=(W-w)/2:(H-h)/2[v]" \
-map "[v]" -map 0:a? -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac out_9x16.mp4
```

## 9. 成片终检（发布前，全部打勾才算通过）
**素材与结构**
- [ ] 每个片段都是 `ready` 的最新终版；没有 `stale`、草稿或来源不明的镜头
- [ ] 严格按 Clip 顺序；`missing` 的已跳过并记录，没有用别的片顶替
- [ ] 剧情钉点全部可见（对照步骤4 钉点清单）

**连续性与节奏**
- [ ] 从头到尾连续看过一遍，接点处没有跳戏、换装、重复动作
- [ ] 情绪句后留了半拍；没有长时间无声的空档

**声音与文字**
- [ ] 关键心声和对白都贴上了，听得清，音量层级对
- [ ] 字幕只有目标语言，和台词定稿逐字一致，和声音同步
- [ ] 画面里没有模型乱生成的外文字、错字；该后期加的可读文字都加上了
- [ ] 没有生成画面里自带的字幕或水印残留

**包装与导出**
- [ ] 封面集数正确；片头片尾用的是系列模板
- [ ] 画幅、分辨率、码率、帧率、响度符合目标平台
- [ ] 音乐音效有授权
- [ ] 时长符合计划（记录实际时长：____）

**交付**
- [ ] 导出文件按 `<剧名>-第<N>集-v<n>.mp4` 命名；工程文件、字幕、配音、素材清单一起归档
- [ ] 用户看完整片并确认；发布由用户决定
