# 错误台账（通用版 G01–G20）

> 来自真实项目踩过的坑。复制到项目里改名 `ERROR-LEDGER.md`，**每犯一个新错就追加一行**（G16、G17……）。
> 用法：步骤4 交审前、步骤6 审图时、步骤7 每条生成前、步骤8 成片终检时，逐项勾选。有一项不过就先修。

| 编号 | 坑 | 定死的改法 | 检查方法 |
|---|---|---|---|
| G01 | 图生视频时把整组分镜都挂成参考 → 角色串台、换脸 | 每条只挂 1 张最佳参考，最多 2 张 | 生成前数参考图张数 |
| G02 | 用户没明确放行就点了生成 | 只有约定的放行口令才能点 | 聊天记录里有没有口令原话 |
| G03 | 心声太密，把动作挤掉了 | 只留推进剧情的判断/动机/决定 + 情绪 | 每条心声问「删了剧情还通吗」 |
| G04 | 节奏压太紧，过渡全删了 | 保留因果桥 + 半拍喘息 | 对照通过稿逐个找因果桥 |
| G05 | 打斗里角色串台（A 的能力被 B 用了） | 写死谁对谁用了什么能力；审图必查 | 每个特效追溯到发出它的人 |
| G06 | 关键动作被换成更好拍、但错误的节拍 | 关键动作因果按原著拍死，禁止换 | 钉点清单逐条对图/片 |
| G07 | 打斗拍成了枪战片（枪阵、枪口怼镜头、弹壳狂欢） | 禁队形；能力软写；枪不抢戏 | 审图搜枪口朝向 |
| G08 | @ 了空壳资产（节点在，没有有效图） | 资产登记三态，只 @「可用」 | 生成前打开那个资产确认有图 |
| G09 | 风格漂移：外国人脸 / 白天 / 古装 / 二次元 | 风格锁写进每条提示词的全局块 | 审图清单 C 节 |
| G10 | 外语台词或字幕进了视频 | 对白心声只用目标语言 + 禁令句 + 固定结尾 | 听片、看字幕区 |
| G11 | 没过闸门就提前开下一步 | 死闸门；用户喊停立即停 | 上一步有没有书面「正式通过」 |
| G12 | 整批盲刷，浪费成本 | 复用优先；单张单条改；被拦最多改写一次 | 重出前先写原因 |
| G13 | 纸面每个分镜都出一张图 | 只出关键节拍 | 每 Clip 出图数 ≤ 关键节拍数 |
| G14 | 成片包装信息写错（封面集数、标题） | 封面/片头信息和集数表对一遍 | 导出前核对 |
| G15 | 人物性别/年龄串了 | 角色表写死性别年龄；资产和分镜都核 | 审图清单「性别/年龄」项 |
| G16 | 旧版、草稿或别的 Clip 的片段混进了成片时间线 | 素材清单四态（ready/regen/missing/stale），文件名带 Clip 号和版本号，只上 `ready` | 每段对照步骤7 索引表核版本；时间线里出现剧本没有的内容先查来源 |
| G17 | 缺片时拿别的片段或草稿顶上（比如集尾钩子） | `missing` 就跳过并记录，要补就正式补生成 | 成片终检「missing 已跳过」项 |
| G18 | 成片没套系列包装：封面集数不对、没有片头片尾 | 用系列封面模板，集数核两遍；片头片尾复用模板 | 导出前对照集数表 |
| G19 | 关键心声或钩子没配音、没字幕，中段变成无声空档 | 配音台本逐条贴到轨上，关键句留气口 | 连续看一遍，找无声超过 2 秒的段落 |
| G20 | 横屏素材直接发竖屏平台（或竖屏裁掉关键信息） | 按平台定画幅：9:16 模糊铺底外壳，或从步骤4 起原生竖屏 | 导出参数核对 + 手机上实际看一遍 |

## 附加常见坑（建议一起检查）
- **自审走过场**：自审写「全部通过」，真看图一半有问题。→ 审图必须看全尺寸原图并裁切放大（步骤6 B 节）。
- **生成画面里要求可读文字**：模型写不对，还可能带外文。→ 文字后期加。
- **地点身份前后不一**：同一个地方在不同图里名字和规模都不一样。→ 写进全局一致性块。
- **能力特效颜色乱**。→ 色彩锁。
- **室内戏跑到室外**。→ 提示词明确「内」和陈设，审图必查。
