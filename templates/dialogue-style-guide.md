# 台词与心声风格指南

> 用在步骤1（初稿）、步骤3（压节奏）、步骤4（分镜台词）、步骤7（视频提示词）。下面的默认值都可以按项目调整。

## 1. 留什么、砍什么
- **留**：所有体现情感、心情、语气，或者推进剧情的句子（判断、动机、决定、情绪爆发）。
- **砍**：重复的、啰嗦的、复述画面的（画面已经拍出来就不要再念一遍）、纯账目式的数字罗列。
- 心声只留推进剧情的，而且要**第一次听就懂**，不要电报句。
- 不要连着好几条心声把动作挤掉：一句判断 + 一个可视动作确认，比三句解说强。

## 2. 像真人说话（「灵动」）
- **语气词**：哎、啧、嗯、嘶、得、行吧、呗、嘛、啊
- **说半截 / 被打断**：「我是这儿的老师，我叫——」「停停停。」
- **自我纠正**：「八成吧？……嗯，差不多。」「不对不对，先别动。」
- **自问自答**：「我干嘛非得冲进去？把它引出来不就完了。」
- **先反应，后信息**：「我去，这么快？」→ 再说情况
- **情绪决定句子长短**：怕、急 → 短促；放松 → 碎碎念；崩溃 → 断句、重复
- **生活化比喻**：「再拖下去，迟早被当夜宵。」
- **数字和机制随口带出来**，不要念报告：✗「剩余能量八单位，胜率八成。」✓「还剩八格……够了，八成能赢吧。」
- **人物各有说话方式**：客气的人急了会结巴（「找、找过了」），孩子说话像孩子。

## 3. 口语和流行语
- 默认口语化、随意一点；可以**适量**用当下的网络流行语（每条视频 0–2 个），主要放在主角的心声和随口吐槽里。
- **不用流行语的地方**：悲剧、哀求、哭喊、被害者的话、关键大喊（指令、咒语、决战台词）。
- 流行语会过时：每个项目开工前和用户确认一次「本项目可用词表」。

## 4. 长度与拆条
- 默认语速上限 **≤4 字/秒**（15 秒视频 ≤60 字，含心声）。
- 一条视频说不完，就拆到连续几条里，话可以跨条接着说；**不要为了塞进一条把台词砍成电报**。
- 一条视频里台词也不要堆太满，留出动作和半拍停顿。

## 5. 语言
- 对白和心声只用目标语言；提示词可以用英文写画面以稳定风格，但台词原样保留目标语言。
- 禁止外语台词、外语字幕、口型念外语。

## 6. 改写示例（虚构）

| 原来（太简约 / 报告腔） | 改后（像人说话） |
|---|---|
| 「先取物资，再撤离。上策。」 | 「东西拿了就跑，别头铁……对，就这么办。」 |
| 「你不能进去。我无法保护你。」 | 「不行，你别进去。真打起来我自己都顾不上，护不住你的。」 |
| 「原来如此，它们在繁殖。」 | 「等等……它在下崽？一窝一窝的……这池子合着是它们的奶瓶啊。」 |
| 「谢谢你。我叫……」「我不想知道。」 | 「那个……谢谢你救了我们，我叫——」「停停停，名字就别说了。」 |

## 7. 自检
- [ ] 每句都能回答「这句留下来是因为情绪 / 语气 / 剧情」
- [ ] 读出来像人话，有语气词、停顿和节奏变化
- [ ] 没有复述画面
- [ ] 字数 ≤ 时长 × 4
- [ ] 流行语没放进悲情或关键的台词里
- [ ] 只有目标语言
